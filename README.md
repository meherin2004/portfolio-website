# Portfolio Website

## Features

- Home Page
- About Me Page
- Education Page
- Project Page
- Achievement Page
- Publication Page
- Contact Me Page
- Download CV
- Responsive Design

## Technologies

- HTML
- CSS

## How to Run

1. Download the project.
2. Open the project folder.
3. Double-click index.html.

## Installation
1. Install Git
2. Clone the repository

```bash
git clone https://github.com/meherin2004/portfolio-website.git
```

3. Open the folder in VS Code.

4. Open index.html in your browser.
