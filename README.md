# Portfolio Website

## Features

- Home Page
- About Page
- Education Page
- Project Page
- Achievement Page
- Publication Page
- Contact Page
- Responsive Design

## Technologies

- HTML
- CSS

## How to Run

1. Download the project.
2. Open the project folder.
3. Double-click index.html.

## Installation

1. Clone the repository

```bash
git clone https://github.com/meherin2004/portfolio-website.git
```

2. Open the folder in VS Code.

3. Open index.html in your browser.
